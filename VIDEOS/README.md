# VIDEOS

Aplicación JavaFX para registro y administración de estudiantes.

## Inicio de sesión
- Usuario: `admin`
- Contraseña: `1234`

La pantalla inicial utiliza el logotipo proporcionado y, después de iniciar sesión correctamente, abre el registro de estudiantes.

## Ejecución
Ejecuta `ni.edu.uam.vieos.Launcher` desde IntelliJ o usa Maven con el plugin de JavaFX.
